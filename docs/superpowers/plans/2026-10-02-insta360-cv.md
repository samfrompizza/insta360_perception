# insta360_cv — ArUco Detector Module Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `insta360_cv` — detect ArUco markers on the raw dual-fisheye frame, draw a bounding box, compute a body-frame quaternion pointing at each marker center, and estimate distance from marker size.

**Architecture:** Mirrors `insta360_geometry`: a pure C++ core library `insta360_cv_core` (Eigen + OpenCV + `insta360_geometry_core`, no rclcpp, no ROS types) plus a thin ROS node `aruco_detector_node` that subscribes to `/dual_fisheye/image`, publishes `~/detections` (custom `DetectionArray`) and `~/visualization`. Reuses `insta360_geometry::FisheyeCamera::pixelToQuaternion` for the pixel→direction mapping — no new geometry code.

**Tech Stack:** C++17, ROS2 Humble, ament_cmake + colcon, Eigen, OpenCV 4.5.4 (`cv::aruco`, `cv::fisheye`, `cv::solvePnP`), cv_bridge, custom `rosidl` messages.

**Spec:** `docs/superpowers/specs/2026-10-02-insta360-cv-design.md`

## Global Constraints

- C++17 (`CMAKE_CXX_STANDARD 17`), ament_cmake, compile options `-Wall -Wextra -Wpedantic`.
- Core library `insta360_cv_core` MUST NOT depend on `rclcpp` or any ROS message type — only Eigen, OpenCV, and `insta360_geometry`.
- No new dependencies beyond what is declared in the spec (no YOLO, no `vision_msgs`, no GPU). OpenCV is **4.5.4** — `cv::fisheye::solvePnP` does NOT exist; distance must use `cv::fisheye::undistortPoints` + pinhole `cv::solvePnP`.
- Per-lens intrinsics are configured as ROS params with inline defaults (`front_*`, `rear_*`, all `480.0`); `LensParams` uses **sub-image lens coordinates** (each lens is 960×960, center (480,480)).
- Quaternion semantics (A1): `q` rotates body `+X` onto the marker direction (`q ⊗ [0,1,0,0] ⊗ q* = [0,x,y,z]`). CV works in the **body frame**; no world coordinates.
- Follow `insta360_geometry` conventions: `rclcpp::Node` subclasses, `declare_parameter` inline defaults, private topics `~/`, CMake `${rclcpp_TARGETS}` style (not `ament_target_dependencies`), executables installed to `lib/${PROJECT_NAME}`, tests via `ament_add_gtest` gated by `if(BUILD_TESTING)`.
- `insta360_geometry` must be built and sourced before building `insta360_cv` (build-order dependency).
- No launch files in this repo. Marker length / dictionary passed as `--ros-args -p`.

```cpp
// Project a marker of the given side length, placed distance_m in front of the
// lens, into equidistant (fisheye) image coordinates (matches EquidistantModel).
std::vector<cv::Point2f> projectMarker(double marker_length, double distance_m)
{
  const double m = marker_length / 2.0;
  const std::vector<cv::Point3f> object{
    {-m, m, static_cast<float>(distance_m)},
    {m, m, static_cast<float>(distance_m)},
    {m, -m, static_cast<float>(distance_m)},
    {-m, -m, static_cast<float>(distance_m)}};

  const cv::Mat K = (cv::Mat_<double>(3, 3) <<
    kLens.fx, 0.0, kLens.cx,
    0.0, kLens.fy, kLens.cy,
    0.0, 0.0, 1.0);
  const cv::Mat D = cv::Mat::zeros(4, 1, CV_64F);

  std::vector<cv::Point2f> image;
  cv::fisheye::projectPoints(
    object, cv::Mat::zeros(3, 1, CV_64F), cv::Mat::zeros(3, 1, CV_64F),
    K, D, image);
  return image;
}

}  // namespace
```

```cpp
#include "insta360_cv/marker_pose_estimator.hpp"

#include <opencv2/calib3d.hpp>

namespace insta360_cv
{

MarkerPoseEstimator::MarkerPoseEstimator(insta360_geometry::LensParams lens)
: lens_(lens)
{
}

std::optional<double> MarkerPoseEstimator::estimateDistance(
  const std::vector<cv::Point2f> & corners_local,
  double marker_length_m) const
{
  if (corners_local.size() != 4 || marker_length_m <= 0.0) {
    return std::nullopt;
  }

  // Marker in its own plane (z=0), corners TL,TR,BR,BL (aruco convention).
  const double m = marker_length_m / 2.0;
  const std::vector<cv::Point3f> object_points{
    {-m, m, 0.0f}, {m, m, 0.0f}, {m, -m, 0.0f}, {-m, -m, 0.0f}};

  const cv::Mat K = (cv::Mat_<double>(3, 3) <<
    lens_.fx, 0.0, lens_.cx,
    0.0, lens_.fy, lens_.cy,
    0.0, 0.0, 1.0);

  // OpenCV 4.5.4 (Humble) has no cv::fisheye::solvePnP. Undistort equidistant
  // (r = f*theta) pixels to pinhole (r = f*tan(theta)) pixels with the same K,
  // then recover pose with the standard pinhole solvePnP.
  const cv::Mat D_fisheye = cv::Mat::zeros(4, 1, CV_64F);
  const cv::Mat D_pinhole = cv::Mat::zeros(5, 1, CV_64F);

  std::vector<cv::Point2f> undistorted;
  cv::Mat rvec;
  cv::Mat tvec;
  try {
    cv::fisheye::undistortPoints(
      corners_local, undistorted, K, D_fisheye, cv::noArray(), K);
    cv::solvePnP(object_points, undistorted, K, D_pinhole, rvec, tvec);
  } catch (const cv::Exception &) {
    return std::nullopt;
  }

  return cv::norm(tvec);
}

}  // namespace insta360_cv
```

```cpp
ArucoDetector::ArucoDetector(
  int dictionary_id,

  int frame_width,

  insta360_geometry::LensParams rear,

  frame_width_(frame_width),
  front_estimator_(front),
  rear_estimator_(rear),
  camera_(&camera)

  if (marker_length_m <= 0.0) {
    throw std::invalid_argument("marker_length_m must be > 0");
  }
  if (frame_width <= 0) {
    throw std::invalid_argument("frame_width must be > 0");
  }
  try {
    dictionary_ = cv::aruco::getPredefinedDictionary(
      static_cast<cv::aruco::PREDEFINED_DICTIONARY_NAME>(dictionary_id));
  } catch (const cv::Exception &) {
    throw std::invalid_argument("unknown dictionary id");

std::vector<Detection> ArucoDetector::detect(const cv::Mat & frame_bgr) const
{
  cv::Mat gray;
  cv::cvtColor(frame_bgr, gray, cv::COLOR_BGR2GRAY);

  std::vector<std::vector<cv::Point2f>> corners;
  std::vector<int> ids;
  cv::aruco::detectMarkers(gray, dictionary_, corners, ids);

  std::vector<Detection> detections;
  detections.reserve(ids.size());

  for (std::size_t i = 0; i < ids.size(); ++i) {
    const cv::Rect bbox = cv::boundingRect(corners[i]);
    const cv::Point2d center(
      bbox.x + bbox.width / 2.0, bbox.y + bbox.height / 2.0);

    const bool is_front = center.x < frame_width_ / 2.0;
    const double offset_x = is_front ? 0.0 : frame_width_ / 2.0;

    std::vector<cv::Point2f> corners_local(4);
    for (std::size_t k = 0; k < 4; ++k) {
      corners_local[k] = cv::Point2f(
        static_cast<float>(corners[i][k].x - offset_x), corners[i][k].y);
    }

    const auto orientation = camera_->pixelToQuaternion(center);
    if (!orientation) {
      continue;  // marker center outside fisheye FOV — skip
    }

    Detection d;
    d.class_id = static_cast<std::uint32_t>(ids[i]);
    d.confidence = 1.0;
    d.center = center;
    d.size_x = bbox.width;
    d.size_y = bbox.height;
    d.orientation = *orientation;

    const MarkerPoseEstimator & estimator =
      is_front ? front_estimator_ : rear_estimator_;
    const auto distance = estimator.estimateDistance(corners_local, marker_length_m_);
    d.distance_m = distance ? *distance :
      std::numeric_limits<double>::quiet_NaN();

    detections.push_back(d);
  }

  return detections;
}

}  // namespace insta360_cv
```

```cpp
#include <cmath>
#include <cstdio>
#include <memory>
#include <string>

#include <Eigen/Geometry>
#include <cv_bridge/cv_bridge.h>
#include <opencv2/imgproc.hpp>
#include <rclcpp/rclcpp.hpp>
#include <sensor_msgs/msg/image.hpp>

#include <insta360_geometry/equidistant_model.hpp>
#include <insta360_geometry/fisheye_camera.hpp>

#include "insta360_cv/aruco_detector.hpp"
#include "insta360_cv/msg/detection.hpp"
#include "insta360_cv/msg/detection_array.hpp"

namespace
{

geometry_msgs::msg::Quaternion toMsg(const Eigen::Quaterniond & q)
{
  geometry_msgs::msg::Quaternion msg;
  msg.w = q.w();
  msg.x = q.x();
  msg.y = q.y();
  msg.z = q.z();
  return msg;
}

}  // namespace

namespace insta360_cv
{

class ArucoDetectorNode : public rclcpp::Node
{
public:
  ArucoDetectorNode()
  : Node("aruco_detector")
  {
    const int frame_width = declare_parameter("frame_width", 1920);
    const double marker_length = declare_parameter("marker_length", 0.15);
    const int dictionary = declare_parameter("dictionary", 9);
    draw_overlay_ = declare_parameter("draw_overlay", true);

    const insta360_geometry::LensParams front{
      declare_parameter("front_fx", 480.0),
      declare_parameter("front_fy", 480.0),
      declare_parameter("front_cx", 480.0),
      declare_parameter("front_cy", 480.0)};
    const insta360_geometry::LensParams rear{
      declare_parameter("rear_fx", 480.0),
      declare_parameter("rear_fy", 480.0),
      declare_parameter("rear_cx", 480.0),
      declare_parameter("rear_cy", 480.0)};

    camera_ = std::make_unique<insta360_geometry::FisheyeCamera>(
      front, rear, frame_width,
      std::make_unique<insta360_geometry::EquidistantModel>());

    detector_ = std::make_unique<ArucoDetector>(
      dictionary, marker_length, frame_width, front, rear, *camera_);

    image_sub_ = create_subscription<sensor_msgs::msg::Image>(
      "/dual_fisheye/image", rclcpp::SensorDataQoS(),
      [this](const sensor_msgs::msg::Image::SharedPtr msg) { onImage(msg); });

    detections_pub_ = create_publisher<insta360_cv::msg::DetectionArray>(
      "~/detections", 10);
    visualization_pub_ = create_publisher<sensor_msgs::msg::Image>(
      "~/visualization", 10);
  }

private:
  void onImage(const sensor_msgs::msg::Image::SharedPtr msg)
  {
    cv_bridge::CvImagePtr cv_ptr;
    try {
      cv_ptr = cv_bridge::toCvCopy(msg, sensor_msgs::image_encodings::BGR8);
    } catch (const cv_bridge::Exception & e) {
      RCLCPP_ERROR(get_logger(), "cv_bridge error: %s", e.what());
      return;
    }

    const std::vector<Detection> detections = detector_->detect(cv_ptr->image);

    insta360_cv::msg::DetectionArray array_msg;
    array_msg.header = msg->header;
    array_msg.detections.reserve(detections.size());
    for (const Detection & d : detections) {
      insta360_cv::msg::Detection m;
      m.header = msg->header;
      m.class_id = d.class_id;
      m.confidence = d.confidence;
      m.center_x = d.center.x;
      m.center_y = d.center.y;
      m.size_x = d.size_x;
      m.size_y = d.size_y;
      m.distance_m = d.distance_m;
      m.orientation = toMsg(d.orientation);
      array_msg.detections.push_back(m);
    }
    detections_pub_->publish(array_msg);

    if (draw_overlay_) {
      cv::Mat viz = cv_ptr->image.clone();
      for (const Detection & d : detections) {
        const cv::Rect bbox(
          static_cast<int>(d.center.x - d.size_x / 2.0),
          static_cast<int>(d.center.y - d.size_y / 2.0),
          static_cast<int>(d.size_x),
          static_cast<int>(d.size_y));
        cv::rectangle(viz, bbox, cv::Scalar(0, 0, 255), 2);

        char label[64];
        if (std::isnan(d.distance_m)) {
          std::snprintf(label, sizeof(label), "id %u ?", d.class_id);
        } else {
          std::snprintf(label, sizeof(label), "id %u %.1fm",
            d.class_id, d.distance_m);
        }
        cv::putText(viz, label, cv::Point(bbox.x, std::max(bbox.y - 5, 15)),
          cv::FONT_HERSHEY_SIMPLEX, 0.5, cv::Scalar(0, 0, 255), 2);
      }
      cv_bridge::CvImage viz_msg(
        msg->header, sensor_msgs::image_encodings::BGR8, viz);
      visualization_pub_->publish(*viz_msg.toImageMsg());
    }
  }

  std::unique_ptr<insta360_geometry::FisheyeCamera> camera_;
  std::unique_ptr<ArucoDetector> detector_;
  bool draw_overlay_ = true;

  rclcpp::Subscription<sensor_msgs::msg::Image>::SharedPtr image_sub_;
  rclcpp::Publisher<insta360_cv::msg::DetectionArray>::SharedPtr detections_pub_;
  rclcpp::Publisher<sensor_msgs::msg::Image>::SharedPtr visualization_pub_;
};

}  // namespace insta360_cv

int main(int argc, char ** argv)
{
  rclcpp::init(argc, argv);
  rclcpp::spin(std::make_shared<insta360_cv::ArucoDetectorNode>());
  rclcpp::shutdown();
  return 0;
}
```
